    applyTransform

    • applyTransform(symbol: TEdge, matrix: TMatrixTransform): void

      Moves, turns or scales this symbol by composing the matrix onto the one it already carries.

      One implementation for every type, where there used to be one per type per operation. A symbol's coordinates are not touched: the matrix is the whole of what a transform changes, so there is no per-type geometry to update and nothing derived left to refresh.

      Override only for a type whose transform is not affine — DecoratorUtil overrides it to a no-op because a decorator follows its targets rather than moving on its own.

      • symbol: TEdge
      • matrix: TMatrixTransform

      Returns void

    • getSVGElement(symbol: TEdge): SVGGraphicsElement

      The element that draws this symbol.
