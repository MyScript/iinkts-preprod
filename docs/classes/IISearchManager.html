    find

    • find(query: string): TSearchMatch[]

      Every occurrence of query, top to bottom then left to right.

      Case- and accent-insensitive, partial ("deriv" finds "derivative"), literal: no pattern syntax. In text, any run of whitespace matches one space, so a phrase can span a line break. Math compares without spaces, in reading order ("3x+2"); exponents and fractions read linearly with no sign of their own except /: a converted x² is found by "x2".

      The highlight follows the last query given here: once the content is synchronized again, it is searched anew and every match of it is highlighted.

      Parameters

      • query: string

        The text to look for; blank finds nothing

      Returns TSearchMatch[]
