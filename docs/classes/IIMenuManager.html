    addItem

    • addItem(
          menu: TMenuName,
          key: string,
          factory: TMenuItemFactory,
          options?: TMenuItemOptions,
      ): void

      Adds an item to a menu, built by factory on every render of that menu, which happens at once if it is shown. It is kept across setConfig. The item goes after the menu's own items, in options.zone (each menu has a default one), or next to options.before/options.after.

      Parameters

      • menu: TMenuName
      • key: string
      • factory: TMenuItemFactory
      • Optionaloptions: TMenuItemOptions

      Returns void

      Throws

      when key is already registered for that menu

      Example

      canvas.menu.addItem("action", "download-png", () => {
        const button = document.createElement("button")
        button.textContent = "PNG"
        button.addEventListener("pointerdown", () => canvas.download("png"))
        return button
      }, { zone: "bar" })

    setConfig

    • setConfig(config: TMenuConfigUpdate): void

      Update menu configuration at runtime and re-render affected sections. Merges deeply into the current config — omitted keys keep their current value.

      Parameters

      • config: TMenuConfigUpdate

      Returns void

      Example

      // Hide only PNG and text export
      canvas.menu.setConfig({ action: { export: { png: false, text: false } } })
      // Disable the entire action menu
      canvas.menu.setConfig({ action: { enable: false } })
