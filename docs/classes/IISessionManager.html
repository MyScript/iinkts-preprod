    Class IISessionManager

    Saves the canvas session to resume it later, even once the server session has expired: the symbols and, from server 4.6.0, the server session as a .iink package.

    It also keeps the last one in memory, taken a while after the changes stop (configuration.persistence): when the server has lost the session, the client starts a new one from it and this manager sends what changed since.

    Access via canvas.session; canvas.exportAs("session") and canvas.download("session") give the same content as a .iinkts file.
