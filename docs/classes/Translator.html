    • Translator

    Class Translator

    Remarks

    A label is looked up in the language with its region (fr_FR), then in the language (fr), then in English; at each level the integrator's labels win over the built-in ones. A key no level knows is shown as is.

    Example

    canvas.i18n.add("fr", { "menu.action.clear": "Tout effacer", "my.button": "Télécharger" })
    canvas.i18n.t("my.button") // "Télécharger" while the recognition is in French
