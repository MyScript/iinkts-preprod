    Class LayoutManager<TCanvas>

    Remarks

    Each occupant gets a host element in its slot, in table order: it renders into that host, so the order holds whatever order the occupants render in. When the layout changes, the hosts move with their content; an occupant that changes slot is announced (see onOccupantMoved) so it can rebuild for its new slot.
