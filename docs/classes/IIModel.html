    • get selectionVersion(): number

Compare this integer instead.

    draftSymbol

    • draftSymbol(id: string): TDraft<TSymbol> | undefined

      A mutable copy of a committed symbol, yours to change until you commitSymbol it.

      This is the replacement for the read-a-clone-then-mutate-it pattern: same cost, but the type says which side of the commit boundary you are on, so IIC-1974 can freeze committed records without every caller having to be re-read to find out whether it writes.

    touch

    • touch(): void

      Stamps the model as changed without going through a mutator.

      Its one caller mutates committed records in place and needs the change to be visible downstream. That pattern is what IIC-1970 converts to draft-then-commit and IIC-1974 makes impossible, and this method goes with it.
