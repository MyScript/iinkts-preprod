Interactive Ink Canvas - Markdown Export

Handwriting → Markdown

canvas.exportAs("markdown") resolves with the Markdown source, derived locally from the JIIX recognition result — no extra server round-trip.

Recognized text becomes paragraphs, math becomes $$...$$. Handy to hand the content to an LLM prompt or to a note-taking app.
The panel refreshes on every exported event, so the Markdown follows what you write without pressing anything.
canvas.download("markdown") saves the same content as a .md file.
The rendered preview below uses marked and DOMPurify from a CDN. They are only there to show the Markdown as a document — iinkTS itself produces the source text and has no rendering dependency.
