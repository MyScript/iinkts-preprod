Diagram Inspector Example

What does the server actually recognize in my diagram?

Every stroke you draw is grouped into a JIIX element: a Node (a shape), an Edge (a line, polyline or arc) or a Text. This page turns that raw recognition result into a readable graph, live, as you draw.

Nodes report their recognized kind (rectangle, circle, rhombus…) and the text found inside them — the same rule the Mermaid and PlantUML exports use for labels.
Edges report which two nodes they join. The server fills connected and ports as soon as the diagram holds more than one shape; when it can't, the endpoints are matched against node boxes instead.
An edge that reaches nothing on one or both ends is flagged dangling — that's exactly what makes an export come out with a missing arrow.
Hover any entry to highlight the ink strokes it was built from, resolved through canvas.jiix, the JIIX query manager.
Try it:
1. Draw two shapes with the Shape tool
2. Write a word inside each one — the panel picks them up as labels
3. Join them with the Edge tool — the edge reports from → to
4. Hover an entry to see which strokes produced it
5. Move one shape away so the edge no longer touches it — it turns dangling
