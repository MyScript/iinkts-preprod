Interactive Ink Canvas — Menu items and overrides

Adding items to the menus, and replacing a menu

canvas.menu.addItem(menu, key, factory, options) adds an item to the action, tool, style or context menu without subclassing it. Each menu has a "bar" and a "dropdown" zone; the item can also go before/after another one, or replace a built-in one.

The action bar gets a Download PNG button (a plain HTMLElement: static) and a stroke count whose badge follows the document (a BaseMenuItem: the menu updates it).
The tool bar gets Reset zoom, and Zoom in/Zoom out sent to its dropdown zone: the tool bar has none of its own, so a … button appears to hold it.
The context menu (right-click or long press) gets a Count the selection quick action, in the row above its list.
A built-in item can move: the configuration hides undo/redo (and the other action bar buttons), and addItem puts a UndoRedoMenuAction in the style menu's bar instead.
For what adding items cannot do, the menu class is replaced through canvasOptions.override.menu: CustomMenuStyle extends IIMenuStyle to allow six brand colors only, without font controls.
