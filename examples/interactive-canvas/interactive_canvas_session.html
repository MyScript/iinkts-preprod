Save and Resume a Session

Pick the work up where it was left

The server drops a session after about an hour without activity. canvas.session keeps what is needed to resume it: the content and, from server 4.6.0, the server session itself as a .iink package — so the work comes back recognized as it was.

As a file canvas.download("session")
Saves a .iinkts file. canvas.session.restore(file) opens it again, on this device or another one. Also in the action menu: Session › Save / Open.
In the browser canvas.session.saved
The session is saved in the browser as you write. Reload the page: the previous one is listed below, never restored on its own — canvas.session.restoreSaved(id) brings it back, canvas.session.discard(id) forgets it.
Automatically
A few seconds after you stop writing, the session is also kept in memory. If the server has lost it when the connection comes back, the canvas starts a new one from it and sends only what changed since — nothing to do.
One tab at a time
Open this page in a second tab: it gets session-storage-unavailable with "locked" and saves nothing in the browser, so the two tabs never overwrite each other.
Settings live in configuration.persistence: storage, key, snapshotDelay, maxAge, maxSize.
