Interactive Ink Canvas - LLM Export

Handwriting → prompt-ready JSON

canvas.exportAs("llm") resolves with flat, ordered content blocks, derived locally from the JIIX recognition result.

Every block is one of three kinds: { type: "text", content }, { type: "math", latex } or { type: "diagram", mermaid }.
Nodes and edges collapse into a single diagram block, so a whole hand-drawn flowchart reaches the prompt as one Mermaid snippet.
The panel refreshes on every exported event, so the structure follows what you write.
canvas.download("llm") saves the same structure as a .json file.
Mix text, math and shapes on the canvas to see all three block kinds appear in order.
