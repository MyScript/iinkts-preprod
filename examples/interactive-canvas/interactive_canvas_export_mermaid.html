Interactive Ink Canvas - Mermaid Export

Hand-drawn diagram → Mermaid

canvas.exportAs("mermaid") resolves with a flowchart TD block, derived locally from the JIIX recognition result.

Draw shapes (rectangle, circle, rhombus…) connected by lines. Write a word inside a shape to label it.
Edge-to-shape connections are resolved geometrically — an edge's endpoint must land inside a shape. An edge that doesn't touch any shape is left out of the flowchart.
The panel refreshes on every exported event, so the flowchart follows the diagram as you draw it.
canvas.download("mermaid") saves the same content as a .mmd file.
The rendered diagram below uses mermaid from a CDN. It is only there to show the syntax as a picture — iinkTS itself produces the text and has no rendering dependency.
