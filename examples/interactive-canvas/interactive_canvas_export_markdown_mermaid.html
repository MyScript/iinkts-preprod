Interactive Ink Canvas - Markdown / Diagram / LLM Export

Digital ink → structured export

canvas.toMarkdown(), canvas.toMermaid(), canvas.toPlantUML() and canvas.toLLM() convert the recognized content, computed locally from the JIIX export — not a server round-trip.

Markdown: recognized text becomes paragraphs, math becomes $$...$$. Handy to hand the content to an LLM prompt.
Mermaid: draw shapes (rectangle, circle, rhombus...) connected by lines — the diagram becomes an editable flowchart TD. Write a word inside a shape to label it.
Edge-to-shape connections are resolved geometrically (an edge's endpoint must land inside a shape) — an edge that doesn't touch any shape is left out of the flowchart.
PlantUML: same diagram, exported as a @startuml/@enduml block instead of Mermaid syntax.
LLM JSON: flat, ordered content blocks (text/math/diagram) — the structured shape an app hands to its own LLM prompt.
