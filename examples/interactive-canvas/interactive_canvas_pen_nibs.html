Interactive Ink Canvas - Pen nibs

One captured stroke, four instruments

A stroke stores where the pen went and when. How wide to draw it at each point is decided when it is drawn, from that same data — so the nib can be changed after the fact and the stroke redraws.

Ballpoint — one width from end to end, blunt ends. Nothing changes it.
Pencil — the default. Width follows the pen's speed: full width where the hand slows, thinner as it accelerates.
Fountain pen — a broad edge held at a fixed angle. Width follows the direction of travel, not the speed: pull across the edge and it lays down the full width, pull along it and it lays down a hairline. Draw a circle to see it.
Brush — the widest range, and the only one that swells past its nominal width where the hand slows.
A pen that reports its own pressure overrides the estimate. A mouse reports a constant, which is read as "no measurement" rather than as a flat one.
