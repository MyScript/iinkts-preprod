Export Files

Download the current content

Write something on the canvas, then either open the Export menu (top-right of the canvas) or use the buttons above the canvas. Both go through the same single entry point: canvas.download(format, options).

JSON canvas.download("json")
The raw symbol model — every stroke, shape and text with full geometry. Best for re-importing content or custom post-processing.
SVG canvas.download("svg")
A vector image of the current content. Scales to any size without losing quality — good for embedding in web pages or documents.
PNG canvas.download("png")
A raster image snapshot of the current content at fixed resolution — good for sharing as a plain picture.
Text canvas.download("text")
Plain text extracted from recognized words only — no drawing or shape data, just what was read.
JIIX canvas.download("jiix")
The raw recognition result from the server, as returned. The source every text/markdown/diagram export is derived from.
PDF canvas.download("pdf")
A print-ready document via the browser's native print dialog. Called without PDF settings it opens a settings dialog first (format/orientation/page mode/scale) — same as the Export menu. The returned promise settles when the dialog closes, cancellation included.
PDF, no dialog canvas.download("pdf", options)
Passing any PDF setting (format/orientation/mode/scale) prints immediately with those values, skipping the dialog entirely.
Options
{ scope: "selection" } exports only the selected symbols, { symbols: [...] } an explicit list, and { filename: "notes" } names the file. Without a name, the file is timestamped: iink-ts-2026-08-26T14-30-15.svg.
To get the content instead of a file, use canvas.exportAs(format) — it resolves with symbols, a string or a Blob depending on the format. "pdf" is the one format it does not accept: printing produces no value.
