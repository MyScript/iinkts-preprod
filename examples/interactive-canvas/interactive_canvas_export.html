Export Formats

Export the current content

Write something on the canvas, then either open the Export menu (top-right of the canvas) or use the buttons above the canvas to trigger the same export programmatically.

JSON canvas.downloadAsJson()
The raw symbol model — every stroke, shape and text with full geometry. Best for re-importing content or custom post-processing.
SVG canvas.downloadAsSVG()
A vector image of the current content. Scales to any size without losing quality — good for embedding in web pages or documents.
PNG canvas.downloadAsPNG()
A raster image snapshot of the current content at fixed resolution — good for sharing as a plain picture.
Text canvas.downloadAsText()
Plain text extracted from recognized words only — no drawing or shape data, just what was read.
PDF canvas.printAsPDF()
A print-ready document via the browser's native print dialog. Called with no arguments, it opens a settings dialog first (format/orientation/page mode/scale) — same as the Export menu.
PDF, no dialog canvas.printAsPDF(false, options)
Passing an options object (format/orientation/mode/scale, all optional) prints immediately with those values, skipping the dialog entirely — useful when calling from your own code.
Every button below calls downloadAsJson()/downloadAsSVG()/downloadAsPNG()/downloadAsText() directly on the canvas instance — the Export menu (top-right) calls the exact same methods. Pass true to export only the selected symbols.
