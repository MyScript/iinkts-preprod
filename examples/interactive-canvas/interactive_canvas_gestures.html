Interactive Ink Canvas — Gestures

Gestures

Write normally — the canvas detects gestures in the ink stream. Use the Gesture menu of the canvas to enable or disable each gesture and choose the action run on detection.

Scratch-out

Scribble rapidly back and forth over content to erase it. Can be turned off.

Surround

Draw a closed loop around symbols. Configurable: select, surround, or highlight.

Strikethrough

Draw through content. Configurable: erase it, or apply a strikethrough decoration.

Underline

Draw below text. Configurable: add an underline, or thicken the strokes above.

Insert

Vertical stroke downward between elements. Configurable: line break or insert space.

Join

Vertical stroke upward between elements. Configurable: merge lines or words, or close the gap to one space.

Gesture menu

Open the Gesture submenu of the canvas menu. Each gesture has its own submenu where you turn it on or off and pick what happens when it is detected.

Detect gesture
Master toggle — when off, every stroke is kept as ink and no gesture is recognized.
Enable
Turns one gesture on or off. Off removes it from the recognition gestures, so the stroke stays as ink; its action selector is then disabled.
Action on detection
What the canvas does when this gesture is recognized:
Surround
Selectdefault · Surround · Highlight
Select — lasso selection.
Surround — decoration ring.
Highlight — highlight decoration.
Strikethrough
Drawdefault · Erase
Draw — add strikethrough decoration.
Erase — delete struck content.
Underline
Drawdefault · Thicken
Draw — underline decoration.
Thicken — increase stroke weight.
Insert
Line breakdefault · Insert
Line break — split across lines.
Insert — insert word space.
Join
Joindefault · CloseGap
Join — glue the two words into one, or pull the next line up.
CloseGap — shrink the gap to one word space; lines stay in place.
Scratch-out has a single behavior, so its submenu only has Enable. A gesture only gets a submenu if it is listed in recognition["raw-content"].gestures when the canvas loads.
