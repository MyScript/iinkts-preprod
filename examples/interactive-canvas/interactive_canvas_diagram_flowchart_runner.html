Flowchart Runner Example

A hand-drawn flowchart is a graph you can walk

Recognition doesn't stop at pretty shapes: it tells you which shape each line joins. That is enough to run the diagram you just drew — step from box to box, and pick a branch whenever there is more than one way out.

Nodes become steps, labelled with the text written inside them.
Edges become transitions. Direction follows the connection reported by the server; draw an arrow head on an end to flip it the way you meant it.
Text written next to an edge — a yes / no beside a decision — is picked up as that branch's label.
The run starts on a node nothing points to, and stops on a node with no way out.
Try it:
1. Draw a box, write Start in it
2. Draw a rhombus below it, write a question inside, join the two with an arrow
3. Draw two boxes under the rhombus, one arrow to each, and write yes / no next to those arrows
4. Hit Run — the current step is outlined on your ink
5. At the rhombus, pick a branch; the trace records the path you took
