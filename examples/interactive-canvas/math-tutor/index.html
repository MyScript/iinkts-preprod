Interactive Ink Canvas - Math Tutor

Math Tutor — handwritten workbook

Solve the equation by hand, one step per line. The canvas reads every line as you write and tells you which one goes wrong, and why.

The right margin shows what the machine read on each line: if a line turns red, check there first whether it read you right.
A line is judged once you start the next one. The last line is judged when you pause, or press Check.
With a pen, your palm is ignored (grabber.inputMode: "auto").
