Diagram Connections Example

How do shape-edge connections work?

When a line, polyline, or arc touches a shape in your diagram, the recognition server detects the connection — and iinkTS keeps the edge attached to that shape as you keep editing.

While writing, a connection is tracked directly on the ink strokes — no need to convert first.
After Convert, the same connection is preserved on the resulting vector shapes and edges.
Moving, resizing, or rotating a connected shape drags its connected edges along with it — before and after Convert.
Erasing a connected shape automatically clears the connection on the edge that pointed to it.
Don't want edges to follow their connected shape? Open the ☰ menu at the top of the canvas → Diagram → untick Follow connected edges. The connection itself (and its survival across Convert) is unaffected — this only turns off the drag-follow behavior.
Try it:
1. Draw a shape (rectangle, circle, ...) with the Shape tool
2. Draw a line or arc with one end touching that shape, using the Edge tool
3. Watch the Connections panel — the edge should report itself connected
4. Select and move the shape — the edge follows, even before converting
5. Hit Convert — the shape and edge become vector symbols, the connection carries over
6. Move, resize, or rotate the shape again — the edge keeps following
7. Erase the shape — the edge's connection clears automatically
8. Toggle ☰ menu → Diagram → Follow connected edges off, then move the shape again — the edge stays put this time
