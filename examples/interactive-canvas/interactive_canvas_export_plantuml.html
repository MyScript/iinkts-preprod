Draw shapes (rectangle, circle, rhombus…) connected by lines. Write a word inside a shape to label it.
Same diagram as the Mermaid export, in PlantUML syntax instead — paste it into your own PlantUML toolchain.
The panel refreshes on every exported event, so the diagram source follows what you draw.
canvas.download("plantuml") saves the same content as a .puml file.
